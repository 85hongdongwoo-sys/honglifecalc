공무원 봉급 위젯·API

공무원 봉급(기본급) 계산기를 내 블로그나 사이트에 복사-붙여넣기 한 줄로 넣는 무료 도구예요. 데이터를 프로그램으로 가져가는 주소(API)도 함께 공개해요.

?이게 뭔가요

아래 계산기를 내 사이트에 그대로 넣을 수 있어요. 방문자가 직종·급수·호봉을 고르면 2026년 월 기본급이 바로 나와요. 공무원 블로그, 임용 준비 카페, 노무·세무 사이트에 넣으면 방문자에게 쓸모가 있고, 계산기 아래 작은 링크로 저희 사이트도 알려져요.

↑ 실제로 움직이는 위젯이에요. 직종·호봉을 바꿔 보세요.

1붙이는 법 (복사-붙여넣기)

내 사이트에서 계산기를 넣고 싶은 자리에 아래 두 줄을 붙이면 끝이에요. 티스토리·워드프레스·네이버 블로그(HTML 모드) 등 HTML을 넣을 수 있는 곳이면 돼요.

<div class="honglife-gongpay"></div>
<script src="https://honglifecalc.com/ko/widget/gong-pay.js" defer></script>

· 위젯은 다른 설치나 라이브러리가 필요 없어요. 광고·추적도 없어요.
· 무료예요. 계산기 아래 ‘홍라이프 계산기’ 링크(출처 표기)만 그대로 두시면 돼요.

2데이터 API (프로그램용)

봉급표 숫자를 직접 프로그램으로 가져가고 싶다면, 아래 주소를 부르면 JSON으로 받을 수 있어요. 사람이 보는 화면이 아니라, 다른 앱·프로그램이 불러 쓰는 창구예요.

GET https://honglifecalc.com/api/gong-pay-2026.json
무료2026년 일반직·경찰·소방·교사 호봉별 월 기본급 전체를 JSON으로 줘요.

받는 모양

fetch("https://honglifecalc.com/api/gong-pay-2026.json")
  .then(r => r.json())
  .then(d => {
    // 일반직 9급 1호봉 월 기본급
    console.log(d.groups["일반직"]["9급"][0]); // 2133000
  });

· 출처 표기(홍라이프 계산기, 링크)만 남겨 주시면 자유롭게 쓰셔도 돼요. 상업적 서비스에 넣기 전엔 한 번 문의 주세요.

i숫자의 출처

봉급표는 공무원보수규정 별표3(일반직)·별표10(경찰·소방)과 2026년 교원 봉급표 기준이에요. 지어낸 값이 아니라 규정에 실린 2026년 기본급 그대로예요. 여기 나오는 건 ‘기본급’ 한 가지라, 실제 받는 돈(수당·공제 포함 실수령액)은 공무원 실수령액 계산기에서 확인하세요.
